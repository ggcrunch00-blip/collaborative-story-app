# 이야기 이어쓰기

초등학교 협력 창작 활동 앱. 교사가 방을 만들고 학생들이 이야기를 돌아가며 이어 씁니다.

## 실행 방법

```bash
npm install
npm run dev
```

접속: http://localhost:3000

## 주요 기능

- 교사가 방 생성 (덩어리 수, 작성/읽기 시간, 이야기 씨앗 설정)
- 학생들이 방 코드 + 닉네임으로 접속
- 실시간 소켓 통신으로 단계 동기화
- 타이머 + 자동 단계 전환
- 완성된 이야기 TXT / Markdown / PDF 저장
- 대기 중 낙서 캔버스

## 테스트 방법

브라우저 두 탭으로:
- 탭 1 → "선생님입니다" → 방 생성
- 탭 2 → "학생입니다" → 방 코드 입력 후 참가
